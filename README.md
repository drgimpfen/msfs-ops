# Microsoft Flight Simulator Standard Operating Procedures (SOPs)

This repository contains highly realistic, chronological Standard Operating Procedures (SOPs) for various aircraft types in **Microsoft Flight Simulator 2024 (MSFS 2024)**. All procedures strictly align with real-world airline operations while taking into account specific aircraft system depth, hardware integration, and ATC network workflows (e.g., **BeyondATC**, **VATSIM**, **IVAO**).

---

- [Transit SOP (Turnaround)](fbw-a320nx/transit-sop.md) – Time-optimized turnaround procedure for multi-leg flights.

### 2. Headwind Airbus A330-900neo / A339X (Passenger)
