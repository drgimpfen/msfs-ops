### 1. Parking & Arrival Checklist

- Set **PARK BRAKE** handle to **SET** / **ON**.
- Set **TAXI LIGHT** switch to **OFF**.
- Keep **AVIONICS MASTER** switch **ON** (if GPU connected) or recycle for quick transit reset.
- Move **LEFT THROTTLE** and **RIGHT THROTTLE** levers to **CUTOFF**.
- Set **BEACON LIGHT** switch to **OFF**.
- Switch **STROBE** light switch to **AUTO**.
- Set **PASS SAFETY** / **SEAT BELTS** switch to **OFF** / **PASS SAFETY**.
- Request Refueling / Baggage loading via **MSFS 2024 EFB** / Ground Services.

---

### 2. Transit Cockpit Preparation & Quick FMS Setup

- Confirm Battery Voltage normal on **MFD** (or **GPU** connected).
- Initialize next leg Flight Plan on **MSFS 2024 EFB** / `planner.flightsimulator.com` and load into avionics.
- Open **FMS 3000** MCDU on Center Console:
  - Press **FPLN** key, clear previous route, and verify new origin, destination, and waypoints.
  - Press **DEP/ARR** key to assign new Departure Runway and SID procedure.
  - Press **PERF** key -> **PERF INIT**:
    - Update Zero Fuel Weight (**ZFW**), Fuel Quantity, and Cruise Flight Level.
  - Press **TAKEOFF REF**:
    - Select Takeoff Flaps (**15°**).
    - Re-calculated Takeoff Speeds (**V1**, **VR**, **V2**) and press **ACCEPT** to send speeds to **PFD**.
- Request ATC IFR Clearance for next leg via ATC network (**BeyondATC** / **VATSIM** / **IVAO**).
- Set Assigned Initial Altitude on **FCP** using **ALT KNOB**.
- Set Runway Heading on **FCP** using **HDG KNOB**.
- Set Local Altimeter Setting (**QNH** / Barometer) on PFD using **BARO KNOB**.
- Set assigned Transponder Code on **ATC Panel**.

### 3. Before Engine Start & Pushback Clearance

- Verify Cabin Door closed and passenger briefing completed.
- Confirm **GPU** disconnected.
- Request Pushback and Engine Start Clearance from ATC.
- Set **BEACON LIGHT** switch to **ON**.
- Check engine zones clear.

---

### 4. Engine Start & After Start Workflow

- **Engine 2 Start:**
  - Press **R ENG START** button.
  - At **12% N2**, move **RIGHT THROTTLE** to **IDLE**.
  - Monitor **ITT**, Fuel Flow, and **N1** acceleration to stable idle.
- **Engine 1 Start:**
  - Press **L ENG START** button.
  - At **12% N2**, move **LEFT THROTTLE** to **IDLE**.
  - Monitor **ITT**, Fuel Flow, and **N1** acceleration to stable idle.
- Set **FLAPS LEVER** to **15°**.
- Set **PITCH TRIM** to Takeoff Green Band index.
- Set **PITOT HEAT** switches to **ON**.
- Perform quick Flight Controls Check.

---

### 5. Taxi, Line-Up & Quick Departure

- Request Taxi Clearance from ATC.
- Set **TAXI LIGHT** switch to **ON**.
- Release **PARK BRAKE** and perform Brake Check.
- Taxi to assigned holding point.
- Upon Line-Up / Takeoff Clearance:
  - Set **LANDING LIGHTS** switches to **ON**.
  - Switch **STROBE** light switch from AUTO to **ON**.
  - Set **PASS SAFETY** / **SEAT BELTS** switch to **ON**.
  - Advance **THROTTLES** to **TO** detent and proceed with standard takeoff workflow.
