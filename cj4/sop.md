### 1. Cockpit Preparation & Electrical Power-Up

- Check **THROTTLES** in **CUTOFF** position.
- Check **GEAR LEVER** in **DN** position.
- Check **ENGINE RUN/STOP** buttons in **STOP** position.
- Switch **BATT** switch to **ON**.
- Check Battery Voltage reading on **MFD** (minimum 24 VDC for battery start).
- Set **EMER LGT** switch to **ARM**.
- Set **PASS SAFETY** / **SEAT BELTS** switch to **PASS SAFETY** or **ON**.
- Set **NAV LIGHTS** switch to **ON**.
- Set **STROBE** light switch to **AUTO**.
- Switch **AVIONICS MASTER** switch to **ON**.
- Request Ground Power Unit (**GPU**) via **MSFS 2024 EFB** / Ground Services if required.
- Initialize **MSFS 2024 EFB** and connect flight plan session.

### 2. Pre-Flight Planning & FMS Setup

- Request ATC IFR Delivery Clearance via ATC network (**BeyondATC** / **VATSIM** / **IVAO**).
- Confirm ATC Route Clearance, Initial Altitude, Assigned SID, and Transponder Squawk Code.
- Cross-check loaded Flight Plan on **MFD MAP** (imported via MSFS World Map or **MSFS 2024 EFB** / `planner.flightsimulator.com`).
- Open **FMS 3000** MCDU on Center Console:
  - Press **FPLN** key to verify origin, destination, route waypoints, and SID/STAR procedures.
  - Press **DEP/ARR** key to select departure runway and assigned SID procedure.
  - Press **PERF** key and navigate to **PERF INIT**:
    - Enter Passenger Count / Cargo Weight.
    - Enter Zero Fuel Weight (**ZFW**) and Fuel Quantity from Operational Flight Plan (**OFP**).
    - Enter Target Cruise Altitude / Flight Level.
  - Navigate to **TAKEOFF REF**:
    - Enter Takeoff Flaps position (**15°**).
    - Enter Runway Elevation, Wind vector, and Outside Air Temperature (**OAT**).
    - Confirm calculated Takeoff Speeds (**V1**, **VR**, **V2**) and press **ACCEPT** to send speeds to **PFD** speedbar.
- Set Departure Runway Heading on **FCP** (**Flight Control Panel**) using **HDG KNOB**.
- Set Assigned Initial Altitude on **FCP** using **ALT KNOB**.
- Press **FD** button on **FCP** to engage Flight Director bars on PFD.
- Set Local Altimeter Setting (**QNH** / Barometer) on PFD using **BARO KNOB**.
- Set Transponder Code on **FMS TUN** page or **ATC Panel** and set Transponder mode to **STBY**.

### 3. Before Engine Start & Pushback Clearance

- Confirm all Cabin Doors and Cargo Hatch are closed and locked via **MFD** status.
- Confirm Ground Power Unit (**GPU**) disconnected if battery start is planned.
- Request Pushback and Engine Start Clearance from Ground / Ramp Control via ATC.
- Set **BEACON LIGHT** switch to **ON**.
- Check parking area and engine intake / exhaust zones clear of ground personnel and equipment.
- Set **PARK BRAKE** handle to **SET** / **ON**.

---

### 4. Engine Start & After Start Workflow

- **Engine 2 (Right Engine) Start:**
  - Press **R ENG START** button momentarily.
  - Monitor **MFD** Engine Display for **N2** rotation and Oil Pressure rise.
  - At **12% N2** minimum, move **RIGHT THROTTLE** lever from **CUTOFF** to **IDLE**.
  - Monitor Fuel Flow, **ITT** (Interstage Turbine Temperature), and **N1** acceleration.
  - Check **ITT** stays within normal starting limits (monitor for hot/hung start).
  - Confirm **R ENG START** button light extinguishes at approximately **45% N2**.
  - Check Engine 2 parameters stabilized at **IDLE**.

- **Engine 1 (Left Engine) Start:**
  - Press **L ENG START** button momentarily.
  - Monitor **MFD** Engine Display for **N2** rotation and Oil Pressure rise.
  - At **12% N2** minimum, move **LEFT THROTTLE** lever from **CUTOFF** to **IDLE**.
  - Monitor Fuel Flow, **ITT**, and **N1** acceleration.
  - Check **ITT** stays within normal starting limits.
  - Confirm **L ENG START** button light extinguishes at approximately **45% N2**.
  - Check Engine 1 parameters stabilized at **IDLE**.

- **After Start Checks:**
  - Verify **DC GENERATOR 1** and **DC GENERATOR 2** connected and online on **MFD** Electrical page.
  - Set **PITOT HEAT** / **ANTI-ICE** switches to **ON** (or **OFF** / **STBY** depending on ambient moisture/temperature).
  - Set **AIR COND / CABIN TEMP** selector to **AUTO**.
  - Set **FLAPS LEVER** to **15°** position.
  - Set **PITCH TRIM** wheel to Takeoff Green Band index.
  - Verify **RUDDER TRIM** and **AILERON TRIM** set to neutral (**0**).
  - Perform Flight Controls Check: Move Control Yoke full forward, full aft, full left, full right, and full left/right Rudder pedals while monitoring control position indication.

### 5. Taxi Clearance & Taxi Workflow

- Request Taxi Clearance from Ground Control via ATC.
- Read back Taxi Route and Hold Short instructions.
- Set **TAXI LIGHT** switch to **ON**.
- Set **RECOG LIGHT** switch to **ON** (if equipped/operating in low visibility).
- Release **PARK BRAKE**.
- Advance **THROTTLES** slightly above **IDLE** to break breakaway friction, then retard to **IDLE**.
- Perform Taxi Brake Check: Apply Toe Brakes gently to verify symmetrical braking response.
- Monitor Nosewheel Steering response during initial turn onto taxiway.
- Verify PFD / MFD Flight Instruments, Attitude Indicator, Heading Bug, and Turn Coordinator during taxi turns.

---

### 6. Before Takeoff & Runway Line-Up

- Request Takeoff Clearance or Line-Up and Wait Clearance from Tower Control via ATC.
- Set **TCAS** mode selector on **FMS TUN** page to **TA/RA**.
- Set Transponder Mode switch to **ALT** / **ON**.
- Set **LANDING LIGHTS** switches to **ON**.
- Switch **STROBE** light switch from **AUTO** to **ON**.
- Set **PASS SAFETY** / **SEAT BELTS** switch to **ON** (Chime cabin crew/passengers).
- Line up on runway centerline and align heading bug on PFD.

---

### 7. Takeoff & Initial Climb

- Advance **THROTTLES** smooth and continuous to **TO** (Takeoff) detent.
- Monitor Engine Parameters (**N1**, **ITT**) reaching Takeoff Thrust limits.
- Announce *"TAKEOFF THRUST SET"*.
- Monitor airspeed acceleration on PFD speedbar.
- At **V1**: Announce *"V1"* (Commit to takeoff).
- At **VR**: Announce *"ROTATE"* – Apply smooth, steady aft yoke pressure to achieve target pitch attitude (**12° - 15°** nose up).
- When established in positive rate of climb: Announce *"POSITIVE RATE, GEAR UP"*.
- Move **GEAR LEVER** to **UP** position.
- At acceleration altitude (minimum **400 FT AGL**):
  - Retard **THROTTLES** from **TO** detent to **CLB** / **CRU** detent.
  - Press **NAV** button on **FCP** to engage FMS Lateral Navigation (or **HDG** for radar vectors).
  - Press **FLC** (**Flight Level Change**) or **VS** button on **FCP** to set climb speed (**160 - 200 KIAS**).
  - Press **AP** button on **FCP** (or via **Winwing Sim URSA Minor AP Disconnect** toggle) to engage Autopilot.
- Passing **1,000 FT AGL** (or flap retraction altitude):
  - Retract **FLAPS LEVER** to **0°** (**UP**).
  - Set **TAXI LIGHT** switch to **OFF**.

---

### 8. Climb & Cruise Operations

- Contact Departure Control / Radar Control as instructed by ATC.
- Passing **10,000 FT MSL**:
  - Set **LANDING LIGHTS** switches to **OFF**.
  - Adjust cabin signs as appropriate.
- Passing Transition Altitude (e.g., **18,000 FT MSL** in FAA airspace or local TA):
  - Set PFD Barometric Reference to **STD** (**29.92 IN HG** / **1013 HPA**) using **BARO KNOB**.
  - Cross-check standby altimeter set to **STD**.
- Leveling at Cruise Altitude (**FL**):
  - Verify Autopilot Mode captures **ALT** on FMA (Flight Mode Annunciator).
  - Verify **THROTTLES** set in **CRU** detent.
  - Monitor Cruise Mach / KIAS speed schedule.
  - Perform periodic Systems & Fuel Quantity checks against SimBrief / Operational Flight Plan (**OFP**).

---

### 9. Descent Preparation & Approach Planning

- Obtain Destination ATIS / Weather Information.
- Select Approach Procedure, Arrival STAR, and Landing Runway in **FMS 3000** (**DEP/ARR** key).
- Review **PERF** / **APPROACH REF** page in **FMS 3000**:
  - Confirm Landing Weight and Fuel Remaining.
  - Verify calculated Landing Speeds (**VREF**, **VAPP**).
  - Send Landing Speeds to PFD speedbar.
- Set Destination Minimums (MDA / DH) on PFD using **MINS KNOB**.
- Request Descent Clearance from Air Route Traffic Control Center (**ARTCC**) via ATC.
- Set Cleared Descent Flight Level / Altitude on **FCP** using **ALT KNOB**.
- Press **VNAV** button or **VS** / **FLC** button on **FCP** to initiate top-of-descent (**TOD**) path.

---

### 10. Descent & Terminal Approach Phase

- Passing Transition Level:
  - Set PFD Barometric Reference to local Destination QNH / Altimeter setting using **BARO KNOB**.
  - Cross-check standby altimeter.
- Passing **10,000 FT MSL**:
  - Set **LANDING LIGHTS** switches to **ON**.
  - Set **PASS SAFETY** / **SEAT BELTS** switch to **ON**.
  - Reduce Airspeed to terminal area limit (**250 KIAS** maximum below 10,000 FT).
- Contact Radar / Approach Control via ATC.
- Confirm Approach Clearance (ILS, RNP, or Visual).
- Press **NAV** or **APPR** button on **FCP** to arm approach lateral/vertical guidance.

---

### 11. Final Approach & Landing

- Upon reaching Flap Maneuvering Speed (below **200 KIAS**):
  - Move **FLAPS LEVER** to **15°**.
- Upon Intercepting Glidepath / Final Approach Course (below **180 KIAS**):
  - Move **GEAR LEVER** to **DN**.
  - Confirm **3 GREEN** Landing Gear lights illuminated on MFD / PFD panel.
  - Set **SPEED BRAKE** handle to **RETRACTED** / **OFF**.
- Passing Outer Marker / Final Approach Fix (below **160 KIAS**):
  - Move **FLAPS LEVER** to **35°** (**FULL**).
  - Establish target approach speed (**VAPP** target).
  - Request Landing Clearance from Tower Control via ATC.
- At Decision Altitude / Height (**DH** / **MDA**):
  - Verify Visual Reference with Runway Environment.
  - Disengage Autopilot by pressing **AP Disconnect Button** on **Winwing Sim URSA Minor Joystick** (or **AP** button on **FCP**).
  - Disengage Yaw Damper if required.
- **Touchdown & Rollout:**
  - Retard **THROTTLES** smoothly to **IDLE** prior to touchdown.
  - Perform main gear touchdown followed by gentle nose gear lowering.
  - Deploy **GROUND SPOILERS** / **SPEED BRAKE** lever to full **EXTEND**.
  - Apply symmetrical manual Toe Braking as required to decelerate to taxi speed.

---

### 12. After Landing & Taxi to Ramp

- Vacate active runway via designated high-speed or standard taxiway.
- Contact Ground Control via ATC for Taxi to Gate / Ramp Clearance.
- Stop aircraft past runway holding point line.
- Switch **STROBE** light switch from ON to **AUTO**.
- Set **LANDING LIGHTS** switches to **OFF**.
- Set **TAXI LIGHT** switch to **ON**.
- Set **FLAPS LEVER** to **0°** (**UP**).
- Set **SPEED BRAKE** lever to **RETRACT** / **OFF**.
- Set **PITOT HEAT** / **ANTI-ICE** switches to **OFF**.
- Set **TCAS** mode selector to **STBY**.
- Set Transponder Mode to **STBY** / **GND**.
- Release Toe Brakes and taxi to assigned apron / parking stand.

---

### 13. Parking & Engine Shutdown

- Taxying into Parking Position / Gate:
  - Follow Marshaller or Visual Docking Guidance System (**VDGS**).
  - Stop aircraft at stop mark.
- Set **PARK BRAKE** handle to **SET** / **ON**.
- Set **TAXI LIGHT** switch to **OFF**.
- Request Ground Power Unit (**GPU**) via **MSFS 2024 EFB** if ground power is available.
- Verify **AVIONICS MASTER** switch remains **ON** if GPU is connected, or prepare for battery shutdown.
- Move **LEFT THROTTLE** lever to **CUTOFF**.
- Move **RIGHT THROTTLE** lever to **CUTOFF**.
- Verify Engine 1 and Engine 2 **N1** / **N2** spooling down to **0%** and **ITT** cooling.
- Set **BEACON LIGHT** switch to **OFF** (signals safe for ground crew approach).
- Set **PASS SAFETY** / **SEAT BELTS** switch to **OFF**.
- Open Passenger Cabin Door via door control.

---

### 14. Securing Aircraft

- Switch **AVIONICS MASTER** switch to **OFF**.
- Set **EMER LGT** switch to **OFF**.
- Set **NAV LIGHTS** switch to **OFF**.
- Switch **STROBE** light switch from AUTO to **OFF**.
- Verify all exterior and interior light switches set to **OFF**.
- Check **PITOT HEAT** and **ANTI-ICE** switches in **OFF** position.
- Check **THROTTLES** confirmed in **CUTOFF** position.
- Check **PARK BRAKE** in **SET** position.
- Switch **BATT** switch to **OFF**.
- Verify all cockpit displays and PFD / MFD screens fully powered down.
- Install Control Surface Locks / Pitot Covers as required for long-term parking.
